1. ЗАЯВКИ С САЙТА — ПУСТЫЕ ПОЛЯ ЗАПОЛНЕНЫ
----------------------------------------------------------------

Было: у заявки с сайта пустые БК, ID счёта и «Клиент» вместо имени.

Причина: клиент сайта пишется в базу ботов как «web», а не именем.
И пополнение баланса LUXON не имеет игрового ID — оба поля выглядели
пустыми.

Стало, и для пополнений, и для выводов:
  • ИМЯ берётся из профиля на сайте. Если его нет — из телеграма,
    в последнюю очередь маскированный chat_id;
  • БК: обычный букмекер — 1XBET, MELBET и т.д.;
    пополнение баланса — «Баланс LUXON»;
    заявка без букмекера — «Не выбран» (раньше просто пусто);
  • ID СЧЁТА: игровой ID, а для пополнения баланса —
    «Аккаунт сайта #12», чтобы не путать с игровым ID;
  • ИСТОЧНИК: новая строка «Сайт» или «Телеграм»;
  • В списке заявок под именем теперь «MELBET • 987654321»
    вместо просто «ID: —».

Имена клиентов берутся пачкой и кэшируются на 30 секунд — список
из 3000 заявок не делает 3000 запросов.


----------------------------------------------------------------
2. УПРАВЛЕНИЕ LUXON — ВЁРСТКА ПОЧИНЕНА
----------------------------------------------------------------

Было: «Доступ открытВход, чаты и заявки работают» одной строкой,
кнопка «Отклонить» на всю ширину.

Причина: правило для строк с переключателями удалилось вместе с
разделом «Букмекеры» в прошлой сборке.

Стало: заголовок и подпись на своих строках, переключатель справа,
одиночная кнопка не растягивается, между блоками нормальные отступы.


----------------------------------------------------------------
3. ЗАЯВКА — ОТДЕЛЬНАЯ СТРАНИЦА ВМЕСТО ОКНА
----------------------------------------------------------------

«Изменить заявку» открывает страницу:
  • шапка: тип, сумма, БК, источник, статус;
  • карточка клиента: имя, ПОЧТА, ТЕЛЕФОН — тап открывает профиль;
  • поля: ID счёта, сумма, букмекер (есть пункт «Не выбран»);
  • «Сохранить изменения» и «Отменить заявку».

Для пополнения при смене суммы пересобираются сумма к оплате и QR.

Окнами остались только короткие подтверждения (причина отказа,
сумма пополнения баланса, код удаления) — там страница была бы лишней.


----------------------------------------------------------------
4. ГОЛОСОВЫЕ, ВИДЕО И ФОТО В ПОДДЕРЖКЕ
----------------------------------------------------------------

БОТ ПОДДЕРЖКИ
Было: «Можно отправить текст или фотографию» — всё остальное отклонялось.
Стало: принимаются фото, голосовые, видео, кружки, гифки и файлы
с картинкой, видео или аудио внутри. Чек по пополнению можно прислать
и видео. Файл скачивается к нам на сервер: ссылки телеграма живут
недолго и содержат токен бота.

С САЙТА
Клиент отправляет из чата поддержки фото, голосовые и видео.
Тип определяется автоматически.

В АДМИНКЕ
Голосовое — плеер с перемоткой, видео — проигрыватель, кружок —
круглый, фото — как раньше. Работает и для сайта, и для бота.

Проверка файлов строгая: тип определяется по содержимому, а не по
имени или заголовку. Файл с расширением .mp4, внутри которого не видео,
не пройдёт. Лимиты: фото 12 МБ, голосовое 20 МБ, видео 64 МБ.


----------------------------------------------------------------
5. САЙТ — ВЕРНУЛИ 10.67.1
----------------------------------------------------------------

Кабинет клиента откачен ровно на 10.67.1, как просили.
Поверх — только скорость и плавность, дизайн не тронут:
  • анимации идут через transform и opacity, без пересчёта раскладки —
    держат 60 к/с на слабых телефонах;
  • длинные списки чатов и сообщений не отрисовываются за экраном;
  • инерционный скролл без «залипания», без протяжки страницы за чатом;
  • появление сообщений и шторок — короткое, без рывка;
  • нажатия отзываются сразу;
  • системная настройка «уменьшить движение» отключает анимации.

Версия сайта в /api/health — 10.67.1, поэтому у клиентов не будет
вечного баннера «доступно обновление».
