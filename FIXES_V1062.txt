LUXON v10.60.2 — белый экран: index.html уезжал пустым

=====================================================================
ПРИЧИНА
=====================================================================
В архивах 10.60.0 и 10.60.1 файл static/app/index.html был размером
0 байт. Пустой HTML — пустая страница. Ни одного скрипта не грузилось,
поэтому и ошибок в консоли не было: белый экран и всё.

Сломал я, в скрипте смены версии:

  open(p,'w').write(open(p).read().replace(...))

Python сначала вычисляет объект, у которого зовёт .write — то есть
open(p,'w'). Это открытие СРАЗУ обнуляет файл. И только потом
выполняется open(p).read(), который читает уже пустой файл. В итоге
в файл пишется пустая строка.

В 10.58 и 10.59 я менял версию в два шага — прочитал, потом записал,
и там всё было цело. В 10.60 сократил в одну строку и получил это.

Подсказка была прямо в твоём логе установки:

  extracting: /home/Luxon/static/app/index.html      <- нулевой размер
  inflating:  /home/Luxon/static/app/app.js          <- нормальные файлы

unzip пишет "extracting" вместо "inflating" для пустых файлов.
Я на это не посмотрел. Виноват.

ИСПРАВЛЕНО: index.html восстановлен, версии проставлены нормально.

тоже сообщение, а не молчание.

=====================================================================
ПРОВЕРКА СБОРКИ
=====================================================================
Добавил tools/check_build.py. Отказывается принимать архив, если:
  - есть файл нулевого размера
  - index.html меньше 400 байт или в нём нет <div id="root">
  - какой-то <script> ссылается на несуществующий или пустой файл
  - не подключён один из шести обязательных скриптов
  - версии в index.html, app.js и server.py разошлись
  - в styles.css не сходятся фигурные скобки

Проверено на сломанной 10.60.1: чекер её отклоняет.

Вместе с tools/check_import_order.py из прошлого раза это закрывает обе
аварии: и падение сервера при импорте, и пустой фронт.

=====================================================================
УСТАНОВКА
=====================================================================
cd /home/Luxon
cp -a server.py server.py.bak.$(date +%F-%H%M)
cp -a static/app static/app.bak.$(date +%F-%H%M)

unzip -o /home/luxon_v10_60_2_web.zip -d /home/Luxon/

# 1. сборка цела: пустых файлов нет, скрипты на месте
python3 tools/check_build.py . || echo "СТОП: битая сборка"

# 2. порядок объявлений
python3 tools/check_import_order.py server.py || echo "СТОП: упадёт при импорте"

# 3. главная: реально импортируем модуль тем же питоном, что и сервис
venv/bin/python -c "import server; print('import OK')" || echo "СТОП: импорт падает"

# 4. index.html не пустой — проверь глазами, должно быть ~3.5 КБ
ls -l static/app/index.html

# только если всё прошло
systemctl restart luxon-admin.service
sleep 3
curl -s localhost:7070/api/health

В браузере обязательно хард-релоад: закрой вкладку целиком и открой
заново, версия скриптов сменилась на 10.60.2.

Откат:
cp -a server.py.bak.ДАТА-ВРЕМЯ server.py
rm -rf static/app && cp -a static/app.bak.ДАТА-ВРЕМЯ static/app
