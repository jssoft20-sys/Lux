# Бот поддержки

Каждое сообщение проходит цепочку: **антифлуд → дедупликация → классификация → ответ из данных системы → (при необходимости) передача оператору с контекстом**.

## Классификация

Категории: `deposit`, `withdrawal`, `payment`, `verification`, `account`, `qr`, `currency`, `technical`, `faq`, `operator`. Правила — регулярные выражения на русском и кыргызском (`services/support.py: _RULES`). Кнопки быстрого доступа: статус пополнения, статус вывода, FAQ, позвать оператора.

## Автоматические ответы

* **Статус пополнения** — по последней заявке пользователя: ожидает оплаты (сколько минут осталось), платёж получен, зачислено, ошибка (оператор уведомлён), истекло, отменено.
* **«Когда будет вывод?»** — реальный статус заявки: создана/в обработке (текст о сроках из настроек `withdraw_sla_text`, без обещания конкретного времени), выполнен (время), отклонён (причина), требует проверки. Если заявка ждёт дольше 24 ч — автоматическая эскалация.
* **Комиссии, лимиты (из настроек касс), реферальная программа, кассы, режим работы, инструкции, QR, ID, валюта, e-mail, блокировка, технические проблемы** — короткие конкретные ответы.
* **Чек/фото без текста** — прикрепляется к текущей заявке и передаётся оператору.

## Передача оператору

Создаётся/обновляется `support_conversations` со статусом `waiting_operator`, приоритетом и `context`: Telegram ID, username, последнее пополнение и вывод (номер, статус, сумма, валюта, касса, ID, время создания, ошибка, история событий), счётчики, наличие QR. Админы получают уведомление (push/UI/Telegram). Пока диалог у оператора (`operator`), автоматика молчит — сообщения клиента идут напрямую в чат админки. После закрытия клиенту предлагается оценка 1–5.

## Антифлуд

Настраивается в админке (Настройки → Поддержка): лимит сообщений в окне, cooldown при превышении (одно предупреждение, дальше тишина), объединение серии сообщений (debounce), подавление повторов одного текста в окне (второй раз — короткий ответ, дальше молча), cooldown повторных эскалаций. Обычный пользователь ограничений не замечает.
