УСТАНОВКА (как обычно)
=====================================================================
cd /home/Luxon

# бэкап
cp -a server.py server.py.bak.$(date +%F-%H%M)
cp -a static/app static/app.bak.$(date +%F-%H%M)

# распаковка
unzip -o /home/luxon_v10_62_0_web.zip -d /home/Luxon/

# 1. сборка цела: пустых файлов нет, скрипты на месте, версии сходятся
python3 tools/check_build.py . || echo "СТОП: битая сборка"

# 2. порядок объявлений
python3 tools/check_import_order.py server.py || echo "СТОП: упадёт при импорте"

# 3. синтаксис + реальный импорт тем же питоном, что и сервис
python3 -m py_compile server.py && echo OK
venv/bin/python -c "import server; print('import OK')" || echo "СТОП: импорт падает"

# только если всё прошло
systemctl restart luxon-admin.service
sleep 3
curl -s localhost:7070/api/health
systemctl status luxon-admin.service --no-pager

В браузере — жёсткая перезагрузка: закрыть вкладку целиком и открыть
заново (версия скриптов сменилась на 10.62.0).

Миграции базы выполняются сами при старте: новые таблицы
web_dm_chatpins, web_dm_hidden и колонки priv_phone, folders_json,
alias, burn. Старые данные не трогаются, откат безопасен.

ОТКАТ:
cp -a server.py.bak.ДАТА-ВРЕМЯ server.py
rm -rf static/app && cp -a static/app.bak.ДАТА-ВРЕМЯ static/app

=====================================================================
ПРОВЕРИТЬ РУКАМИ ПОСЛЕ УСТАНОВКИ (2 минуты)
=====================================================================
1. Чаты открываются первой страницей; свайп строки чата вправо/влево.
2. «+» в строке папок → создать папку, накидать чаты.
3. Поиск: ввести слово из старой переписки → секция «Сообщения».
4. Профиль собеседника: телефон виден, тап по аватару — на весь экран,
   «В контакты» — спросит своё имя.
5. Скрепка → фото → порисовать, обрезать, выбрать «🔥 1 раз» → у
   получателя фото откроется один раз и сгорит.
6. Голосовое: тап в середину волны — перемотка.
7. Ссылка в чате — откроется во внутреннем браузере.
8. LuxOn: /start — оформление с эмодзи и зелёными кнопками.

=====================================================================
ПАМЯТКА ПРО TURN (пункт 1.15, звонки при строгом NAT)
=====================================================================
Когда оба абонента на мобильном интернете, прямое P2P может не
пробиться — нужен свой TURN-релей (coturn). Это делается на сервере,
кода мессенджера не касается:

  apt install coturn
  # /etc/turnserver.conf:
  #   listening-port=3478
  #   fingerprint
  #   lt-cred-mech
  #   user=luxon:СЛОЖНЫЙ_ПАРОЛЬ
  #   realm=ваш-домен
  systemctl enable --now coturn

Потом пропишите в config.json (web_app) поля turn_url / turn_user /
turn_pass (поля уже читаются кодом звонков) и перезапустите сервис.
Порт 3478/udp+tcp должен быть открыт в фаерволе.
