# Lux — Shazam для фильмов

Узнать название фильма по обрывку, который застрял в голове:

- **по описанию** — пересказ сцены, реплика, «помню только, чем кончилось»;
- **по кадру** — скриншот из шортса или рилса;
- **по звуку** — записанный с колонки фрагмент или сам клип: разбираются и реплики героев, и музыка.

<p align="center"><i>Работает без единого API-ключа (офлайн-индекс), но раскрывается с ключами.</i></p>

## Быстрый старт

```bash
npm install
cp .env.example .env     # заполни то, что есть; можно ничего не заполнять
npm start                # http://localhost:3000
npm test                 # 21 тест, без сети
```

При старте в консоли видно, какие движки включились, а какие спят без ключа. То же самое — в UI по кнопке «Движки».

## Как это работает

Один запрос идёт сразу по нескольким независимым движкам, их догадки сливаются в общий рейтинг по формуле «noisy-or» (два слабых независимых сигнала дают более уверенный общий, но ни один не даёт 100%).

| Путь | Что делает | Чем включается |
| --- | --- | --- |
| Описание | Claude разбирает пересказ и проверяет версии веб-поиском | `ANTHROPIC_API_KEY` |
| Кадр | Claude смотрит изображение: актёры, грим, эпоха, цветокор, шрифт субтитров | `ANTHROPIC_API_KEY` |
| Звук → речь | Любой OpenAI-совместимый `/audio/transcriptions` (OpenAI, Groq, локальный whisper) превращает диалог в текст, дальше его ищет Claude | `ASR_API_URL` |
| Звук → музыка | AudD снимает аудио-отпечаток трека; саундтрек часто и есть ответ | `AUDD_API_TOKEN` |
| Проверка | TMDB подтверждает, что фильм существует, и даёт постер, год, ссылку | `TMDB_API_KEY` |
| Офлайн-индекс | Лексический поиск по `data/movies.json` — страховка, работает всегда | — |

Важная деталь: **непроверенный в TMDB кандидат теряет 40% уверенности и помечается предупреждением.** Модель может выдумать правдоподобное название — этот шаг ловит такие случаи.

Каждый ответ содержит блок «Как искали»: какой движок отработал, какой пропущен и почему. Никакой магии в чёрном ящике.

## API

```bash
# по описанию
curl -X POST localhost:3000/api/identify/text \
  -H 'Content-Type: application/json' \
  -d '{"description":"мужик без памяти, татуировки-заметки, сюжет задом наперёд"}'

# по кадру
curl -X POST localhost:3000/api/identify/frame -F image=@frame.jpg -F hint='вроде 90-е'

# по звуку (аудио или видео)
curl -X POST localhost:3000/api/identify/audio -F audio=@clip.mp4

# что включено
curl localhost:3000/api/status
```

Ответ:

```json
{
  "candidates": [
    {
      "title": "Помни", "original": "Memento", "year": 2000,
      "confidence": 0.82, "verified": true,
      "poster": "https://image.tmdb.org/...",
      "reasons": ["Татуировки-заметки и обратная хронология — уникальная примета"],
      "sources": ["claude", "local"]
    }
  ],
  "question": "",
  "steps": [{ "engine": "claude", "status": "ok", "note": "кандидатов: 3" }]
}
```

## Честно о том, чего тут нет

- **«Для фильмов никто не делал» — не совсем так.** Похожее умеют Google Lens, сервисы вроде WhatIsMyMovie, ACR-технологии Gracenote/ACRCloud в смарт-ТВ и сабреддит r/tipofmytongue. Чего нет — одного удобного места, где работают сразу все три способа: текст, кадр и звук. Lux закрывает именно это.
- **Настоящий аудио-отпечаток по звуковым дорожкам фильмов** (как у Shazam для песен) требует лицензированной базы фингерпринтов всех фильмов — её нельзя собрать в одиночку. Поэтому звук тут распознаётся двумя обходными путями: речь → текст и музыка → трек.
- Файлы не сохраняются: кадр и звук живут в памяти процесса и умирают вместе с запросом.
- Офлайн-индекс — это демонстрация на ~36 фильмах, а не полноценная база. Серьёзная точность появляется вместе с `ANTHROPIC_API_KEY`.

## Что дальше

- Индекс субтитров (OpenSubtitles) — поиск по дословной реплике без обращения к модели.
- Перцептивные хеши кадров популярных фильмов — мгновенный ответ по картинке.
- История запросов и «уточняющий диалог»: модель уже возвращает `question`, осталось довести до второго круга.
- Расширение локального индекса до нескольких тысяч фильмов.

## Структура

```
server/
  index.js            express-приложение
  config.js           переменные окружения + статус движков
  routes/identify.js  три эндпоинта
  lib/pipeline.js     оркестровка движков
  lib/rank.js         слияние и ранжирование кандидатов
  lib/text.js         токенизация и грубый стеммер
  providers/          claude · tmdb · asr · audd · local-index
public/               одностраничный фронтенд без сборки
data/movies.json      офлайн-индекс
test/                 node:test, без сети
```
