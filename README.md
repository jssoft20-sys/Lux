# Telegram — мессенджер / соц-сеть

Полнофункциональный клон интерфейса Telegram (iOS-стиль) на Node.js + WebSocket.
Реальный обмен сообщениями в реальном времени, звонки (WebRTC), боты, стикеры,
опросы, голосовые сообщения, форматирование текста и многое другое.

> Собрано как **оригинальная реализация** по мотивам дизайна Telegram.
> Демо-данные нейтральные (примеры пользователей, новостной канал, эхо-бот).

---

## ⚡ Быстрый старт (папка /home/Telegram, порт 8044)

Скопируйте и вставьте это в терминал сервера — команды создадут папку,
распакуют архив, установят зависимости и запустят сервер на порту **8044**:

```bash
# 1. Создаём папку
sudo mkdir -p /home/Telegram
sudo chown -R "$USER" /home/Telegram
cd /home/Telegram

# 2. Распаковываем архив (положите telegram-app.zip в /home/Telegram)
unzip -o telegram-app.zip -d /home/Telegram

# 3. Ставим зависимости
npm install --no-audit --no-fund

# 4. Запускаем на всех интерфейсах, порт 8044
PORT=8044 HOST=0.0.0.0 node server/index.js
```

Либо одной командой через готовый скрипт:

```bash
cd /home/Telegram && PORT=8044 ./start.sh
```

После запуска в консоли появится адрес:

```
Local:   http://localhost:8044
Network: http://<IP-ВАШЕГО-СЕРВЕРА>:8044
```

Открывайте `http://<IP-сервера>:8044` в браузере.

## 🧩 Что реализовано

- **Чаты** — личные, группы, каналы, «Избранное», real-time доставка, непрочитанные, папки (Все / Личные / Боты / Группы / Новые + свои).
- **Сообщения** — ответы, пересылка, редактирование, удаление, **закреплённые сообщения**, реакции, отметки о прочтении (✓✓), просмотры.
- **Форматирование текста** — `**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `моно` ``, `||спойлер||`, ссылки, @упоминания, #хэштеги.
- **Голосовые сообщения** — запись с микрофона (MediaRecorder) с волной и плеером.
- **Стикеры / эмодзи / GIF** — панель-пикер с наборами.
- **Опросы** — обычные, с несколькими ответами и режим викторины; голосование в реальном времени.
- **Превью ссылок** — сервер подтягивает OpenGraph-мета.
- **Контакты** — список, добавление по @username / телефону, поиск.
- **Звонки** — аудио и **видеозвонки** через WebRTC (P2P между браузерами), журнал звонков.
- **Поиск** — глобальный: люди, чаты, сообщения, каналы.
- **Боты** — эхо-бот, поллбот, BotFather-стиль, стикер-бот; inline-кнопки, авто-ответы, команды.
- **Юзернеймы** — @username, смена, поиск по нему.
- **Конфиденциальность** — настройки видимости (номер, время захода, фото, звонки, сообщения и т.д.).
- **Устройства** — активные сеансы, завершение сеанса.
- **Анимации** — переходы экранов, всплывающие реакции, индикатор набора, «прыгающие» стикеры, splash.
- **Темы** — светлая и тёмная.
- **Профиль** — аватар-градиенты, «О себе», персональные цвета, Premium-бейдж, общие медиа/файлы/голосовые/ссылки.

## 🗂 Структура

```
server/            бэкенд (Express + Socket.IO)
  index.js         точка входа, статика, порт
  db.js            JSON-хранилище (без нативных зависимостей)
  service.js       бизнес-логика (чаты, сообщения)
  socket.js        real-time события + сигналинг звонков
  routes.js        REST API
  bots.js          движок ботов
  seed.js          демо-данные
public/            фронтенд (ванильный JS, без сборки)
  index.html
  css/*            стили (iOS-тема Telegram)
  js/app.js        ядро: состояние, роутер, сокет, API
  js/ui.js         UI-компоненты
  js/format.js     форматирование текста
  js/screens/*     экраны (чаты, чат, контакты, звонки, поиск, настройки…)
  js/features/*    голос, стикер-пикер, опросы, WebRTC
data/              база (создаётся автоматически при первом запуске)
uploads/           загруженные файлы / голосовые
```

## ⚙️ Настройки

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `PORT`     | `8044`       | порт сервера |
| `HOST`     | `0.0.0.0`    | интерфейс (0.0.0.0 = доступ по IP) |

Сброс базы к демо-данным:

```bash
rm -f data/db.json && node server/index.js   # пересоздаст демо
# или
npm run seed
```

### Автозапуск (systemd, необязательно)

```ini
# /etc/systemd/system/telegram.service
[Unit]
Description=Telegram clone
After=network.target
[Service]
WorkingDirectory=/home/Telegram
Environment=PORT=8044
Environment=HOST=0.0.0.0
ExecStart=/usr/bin/node server/index.js
Restart=always
[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now telegram
```

## 📞 Про звонки

Аудио/видео — реальный WebRTC P2P между двумя браузерами. В локальной сети
работает «из коробки» (STUN Google). Для звонков нужен `https://` **или**
`http://localhost` (браузеры разрешают камеру/микрофон только в защищённом
контексте). Для доступа по IP по HTTP голосовые/звонки могут потребовать
запуска за HTTPS-прокси (nginx + сертификат).
