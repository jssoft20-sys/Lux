# PayGo 1.13.9.69

**Живые Баланс/Лимит 1xBet — через вход в кабинет (Hydra), как в приложении.**

## Что показал probe (на 1.13.9.68)

- `cashier-report` (с `login`) → `HTTP 200`, но это **оборот смены**, а не
  баланс: `depositAmount 14855.6`, `withdrawalAmount 992`, счётчики, %
  комиссии. Баланса/лимита там нет.
- `cashbox.getBalance` (гейтвей `/api/`) с токеном APP-2-APP → `unauthorized`.

Вывод: у **интеграционного** API кассы (5 методов + отчёт) баланса нет
в принципе. Живые `6 406.36 / 13 593.64` отдаёт только гейтвей, а токен
к нему даёт **вход в кабинет** (Ory Hydra) — тот же, что делает сайт
`app.mob-cash.com`, когда кассир заходит в браузере.

## Что меняется

Адаптер теперь повторяет **вход в кабинет** (только чтение, логин/пароль/код
кассы — ваши же), получает токен гейтвея и вызывает `cashbox.getBalance`:

```
GET  /hydra/oauth2/auth   (client_id 4e779103…, scope offline, prompt consent)
POST /authentication/login    { login, password, appMode:"cashbox", cashboxCode }
POST /authentication/consent  { client_id, grant_scope }
→ token.accessToken  →  POST /api/  cashbox.getBalance { cashboxID } → { balance, limit }
```

- `balance` → наш **«Вывод»**, `limit` → наша **«Касса»** (как на главном
  экране приложения кассы).
- Токен кабинета кэшируется на 8 минут; `unauthorized` → один перелогин.
- Любой сбой → откат на отчёт кассира, затем на «Касса на связи». **Регрессии
  нет.** Вход кабинета идёт с сервера (его IP касса принимает) — гео-подмена
  не нужна и не делается.

## Честно про статус

Шаги 2–3 (ввод логина/пароля и согласие) я не могу проверить со своей
стороны, не рискуя вашей кассой (вход с чужого IP). Поэтому `mobcash-probe`
печатает **каждый шаг** входа в кабинет — один запуск на сервере покажет,
получен ли токен и что вернул `cashbox.getBalance`. Если где-то 400/иное —
поправлю точечно по логу.

## Код

Меняются только `providers/mobcash.py` и `cli.py`. Фронтенд не трогается.
Установщик тот же терпимый. 18/18 тестов. Дельта пересобирается из текущего
1.13.9.68 (только 2 файла).

## Установка и проверка

1. `installer/paygo-1.13.9.69-paste.txt` одним блоком в терминал (root).
2. Главный экран → Ctrl+F5. Если чисел нет — пришлите вывод:
   ```
   sudo -u paygo /home/PayGo/venv/bin/paygo-admin mobcash-probe
   ```
   блок `=== вход в кабинет (Hydra) → cashbox.getBalance ===`.
