LUXON WEB v10.64.0 — КЛАВИАТУРА БОТА КАК В TG + ЖИВОЙ ИНТЕРФЕЙС
=====================================================================
Включает всё из 10.61–10.63. Ставится одним архивом.

ЧТО НОВОГО

1. ВАЖНЫЙ ФИКС: бот LuxOn брал букмекеров и лимиты сумм из секции
   web_app конфига, а касса и Telegram-бот — из корня config.json.
   На проде из-за этого бот мог показывать «Пополнение временно
   недоступно» или дефолтные лимиты. Теперь бот читает ровно те же
   данные, что касса: config.json → bookmakers (deposit_min/max,
   включён/выключен, порядок) — всё живое, из сервера.

2. Кнопки бота — снизу, у поля ввода, как в Telegram (reply-клавиатура):
   меню «Пополнить/Вывести», сетка букмекеров, суммы, «❌ Отмена» —
   всё лежит панелью под инпутом и меняется с каждым шагом диалога.
   Кнопки прошлых сообщений остаются в истории под пузырями.

3. Свайпы по чатам — новый дизайн: тянешь строку вправо — из-под неё
   вырастает круглая зелёная кнопка «Закрепить» (иконка растёт вместе
   с пальцем, на пороге — вибрация и вспышка), влево — красная
   «Удалить». Отпустил на пороге — сработало.

4. «Живой» интерфейс: у каждого нажимаемого элемента теперь есть
   мгновенный физический отклик (сжатие/подсветка) — строки чатов,
   кнопки, папки, иконки, клавиатура бота. Плюс убран системный
   серый «блик» браузера при тапе.

УСТАНОВКА (как обычно)
=====================================================================
cd /home/Luxon
cp -a server.py server.py.bak.$(date +%F-%H%M)
cp -a static/app static/app.bak.$(date +%F-%H%M)

unzip -o /home/luxon_v10_64_0_web.zip -d /home/Luxon/

python3 tools/check_build.py . || echo "СТОП: битая сборка"
python3 tools/check_import_order.py server.py || echo "СТОП: упадёт при импорте"
python3 -m py_compile server.py && echo OK
venv/bin/python -c "import server; print('import OK')" || echo "СТОП: импорт падает"

systemctl restart luxon-admin.service
sleep 3
curl -s localhost:7070/api/health

Браузер: полностью закрыть вкладку и открыть заново (версия 10.64.0).

ПРОВЕРКА (1 минута)
1. LuxOn → /start: меню зелёными кнопками ПОД полем ввода.
2. «Пополнить» → сетка букмекеров снизу — ровно те БК, что включены
   в админке; выключи одну БК в настройках — пропадёт и у бота.
3. ID → «✅ ID найден + ФИО», суммы с лимитами твоей БК.
4. Чаты: медленно потяни строку вправо — кнопка «Закрепить» вырастает,
   на пороге вибрация; влево — «Удалить».
