# PayGo 1.13.9.72

**Кнопки меню видно везде (старый Android/TG) + защита при выключенном букмекере.**

## 1. Кнопки не показывались на старых/Android Telegram

Постоянное нижнее меню (Пополнить / Вывести / Помощь) несло на кнопках
`style="primary"` — это поле только для inline-кнопок (Bot API 9.4+).
Сервер его принимает, но **старые клиенты роняют всю клавиатуру** —
поэтому приветствие и подсказка «Главное меню» видны, а самих кнопок нет
(как на скринах). Теперь кнопки нижнего меню очищаются до стандартных
полей — меню рисуется на любом клиенте.

## 2. Клиент не должен случайно пополнить «не тот» букмекер

Раньше, если 1xBet выключен, а активна только вторая касса, клиента
**молча** бросало в неё (авто-выбор) — он платил, думая что это 1xBet, и
ID мог уйти не туда. Теперь:

- Авто-выбор только когда касса **одна-единственная** во всём боте.
- Если касс несколько — всегда показываем выбор; выключенные помечены
  «⛔ … — временно выключен».
- Нажал на выключенную — бот прямо говорит «временно выключен, выберите
  другую» (и пропустит, только если касса снова включилась).

Клиент всегда **осознанно** выбирает букмекера — денег «за 1xBet» на
чужой счёт/ID больше не уйдёт. Сохранённые ID и так привязаны к своей
кассе, а на экране ввода ID видно название кассы.

## Код

Только бот: `bot/paygobot/telegram.py` (клавиатура), `main_bot.py`
(выбор кассы + обработчик выключенной). Фронтенд и остальное не тронуты.
223 теста. Дельта пересобирается из текущего 1.13.9.70/1.13.9.71.

## Установка

`installer/paygo-1.13.9.72-paste.txt` одним блоком в терминал (root).
После установки боты перезапустятся — проверь меню на телефоне.
