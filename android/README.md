# Приложение курьера Sprinter Go

Оболочка вокруг веб-приложения водителя плюс то, чего браузер на телефоне не
умеет: связь и координаты при погасшем экране, звук на новый заказ, значок на
рабочем столе.

Ни одной сторонней библиотеки. Всё — WebView, геолокация, уведомления, поток
событий — есть в самом Android. Firebase нет: уведомления приложение показывает
само, поток заказов держит само. Значит, не нужен ни аккаунт Google, ни чужие
ключи, и оно работает даже там, где сервисов Google нет.

## Что внутри

```
app/src/main/java/kg/sprintergo/courier/
  MainActivity.java   единственный экран: WebView на /go/courier, разрешения
  ShiftService.java   служба смены: координаты и поток заказов при погасшем экране
  Sse.java            чтение потока событий с сервера, с выдержкой при обрывах
  Bridge.java         мостик: веб говорит «вот токен», «я на линии», «я ушёл»
  Prefs.java          токен и адрес сервиса
```

Веб и приложение общаются тремя вызовами. Со стороны страницы это:

```js
if (window.SprinterGo) {
  SprinterGo.setToken(token);   // вошёл
  SprinterGo.setShift(true);    // вышел на линию
  SprinterGo.setShift(false);   // ушёл с линии
  SprinterGo.clearToken();      // вышел из аккаунта
}
```

Внутри приложения `navigator.userAgent` содержит `SprinterGoApp/` — по этому
признаку веб не предлагает «скачать приложение» тому, кто уже в нём.

## Собрать

Нужны Java 17+ и Android SDK с платформой 34.

```bash
export ANDROID_HOME=/путь/к/android-sdk
gradle assembleRelease        # подписанный файл для раздачи
gradle assembleDebug          # для проверки на своём телефоне
```

Готовый файл: `app/build/outputs/apk/release/app-release.apk`.

## Выложить водителям

```bash
bash ../platform/tools/publish_apk.sh app/build/outputs/apk/release/app-release.apk
```

Скрипт кладёт файл в `platform/web/app/` и пишет рядом `version.json`. После
этого на экране входа водителя с Android появляется полоса «Скачать». Пока файла
нет — полосы тоже нет.

## Про подпись

Ключ лежит в `keystore/sprintergo.jks`, пароль `sprintergo` (меняется
переменными `SG_STORE_PASS` и `SG_KEY_PASS`).

**Этот ключ нельзя терять.** Android разрешает обновлять приложение только тем
же ключом, которым оно подписано в первый раз. Потеряете — водителям придётся
удалять старое приложение и ставить новое вручную. Держите копию ключа отдельно
от репозитория.

## Почему постоянное уведомление

«Sprinter Go — вы на линии» висит, пока идёт смена, и убрать его нельзя. Это не
прихоть: современный Android выгружает из памяти всё, что не показывает такого
уведомления, и через пару минут после того, как водитель погасит экран, заказы
перестали бы приходить. Уведомление — плата за то, чтобы связь держалась.
