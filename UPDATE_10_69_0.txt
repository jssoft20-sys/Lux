LUXON WEB v10.69.0 — ДИЗАЙН ПЕРЕПИСАН ПОД TELEGRAM iOS (СВЕТЛАЯ ТЕМА)
=====================================================================
Включает всё из 10.61–10.68. Функции не тронуты, переписан ВЕСЬ вид.

Сделано по твоему архиву референсов (49 скринов реального Telegram iOS
в светлой теме + видео). Расположение, отступы, шрифты, кнопки, цвета
светлого режима — как в Telegram, акцент — наш зелёный.

Проверено на реальных скриншотах в браузере (chats, диалог, профиль):
- СВЕТЛАЯ тема по умолчанию (как в референсах). Тёмная — чипом в профиле.
- Список чатов: белые строки во всю ширину с тонкими разделителями
  (не карточки), аватары 54px, имя/сообщение/время как в Telegram,
  зелёные бейджи непрочитанных.
- Фильтры сверху — плоские вкладки с зелёным подчёркиванием активной
  (Все / Личные / Боты / Непрочитанные), без «пилюль».
- Шапка/топбар — тонкая, стеклянная (blur), баланс слева, иконки справа.
- Диалог: обои как в Telegram, входящий белый пузырь, исходящий —
  зелёный с белой галочкой, плашка «Сегодня», шапка звонок/видео/поиск.
- Композер: поле-пилюля, стикер/фото/микрофон.
- Контекст-меню сообщения — как в iOS: ряд реакций сверху, пункты
  Ответить/Скопировать/Закрепить/Переслать/Удалить (иконка справа).
- Профиль/настройки: сгруппированные строки, зелёные иконки-квадратики,
  чипы действий, бейджи установки приложения.
- Нижние вкладки — iOS tab bar, активная зелёная, Касса приподнята.

Все функции сохранены: боты и управление ботами (LuxFather), касса
LuxOn (QR, банк-кнопки, заявка→успех), Bot API по токену, микрофон,
редактор фото, одноразовые фото, реакции, стикеры, свайпы, контакты,
папки, звонки.

Про «1:1 как Telegram»: раскладка, отступы и стиль сделаны по вашим
референсам светлого режима, цвета — наши (зелёный вместо синего).
Это цельный iOS-стиль, а не патч поверх старого.

УСТАНОВКА:
cd /home/Luxon
cp -a server.py server.py.bak.$(date +%F-%H%M)
cp -a static/app static/app.bak.$(date +%F-%H%M)
unzip -o /home/luxon_v10_69_0_web.zip -d /home/Luxon/
python3 tools/check_build.py . && python3 tools/check_import_order.py server.py
venv/bin/python -c "import server; print('import OK')"
systemctl restart luxon-admin.service && sleep 3 && curl -s localhost:7070/api/health
Затем полностью закрыть вкладку и открыть заново (10.69.0).
Тема по умолчанию теперь СВЕТЛАЯ. У кого была сохранена тёмная —
останется; сменить можно в Профиле → чип «Тема».
