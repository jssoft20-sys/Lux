ЧТО НОВОГО В 10.63.0

Бот LuxOn — теперь точная копия Telegram-бота (сверено с main_bot.py):
  - Приветствие слово-в-слово: «Привет, Имя  | LUX ON! 🕒 …
    ✅Пополнение | Вывод … 🌐 Работаем 24/7 … 📞 Оператор …»
  - Проверка игрового ID у букмекера, как в ТГ: «✅ ID найден /
    👤 Фамилия Имя», при ошибке «❌ ID не найден…»
  - Сохранённые ID из прошлых заявок — зелёными кнопками
  - Суммы: «💰 Пополнение счета / Минимум / Максимум» из настроек БК,
    пресеты 50…10000 как в ТГ, проверка лимитов
  - После создания заявки бот показывает ТОТ ЖЕ платёжный текст с
    реквизитами, что и Telegram-бот, + кнопки «🏦 Открыть заявку» и
    «❌ Отменить пополнение» (отмена реально закрывает заявку)

Бот-платформа — «у них на серверах всё сами прописывают», как ты просил.
Внешний скрипт клиента работает по токену (аналог Telegram Bot API):
  GET  /api/lux/bot/me                     — getMe
  GET  /api/lux/bot/updates?after_id=N     — getUpdates: текст И нажатия
       кнопок (поле callback = callback_data)
  POST /api/lux/bot/sendMessage            — {user_id, text, buttons:
       [[{"t":"Оплатить","d":"pay","c":"g"}]]} — инлайн-кнопки с цветом
       (g зелёная, r красная, b синяя)
  POST /api/lux/bot/setCommands            — {commands:[{command,
       description, reply}]} — reply бот отвечает сам, без скрипта
  POST /api/lux/bot/setStart               — {start_text, description}
  Нажатие кнопки матчится на команду с тем же именем — бот отвечает
  сам; незнакомые callback уходят скрипту через updates.
  Заголовок авторизации: X-Bot-Token: <токен из LuxFather>

Фиксы:
  - Двойная отправка сообщения (двойной тап/Enter) — заблокирована
  - Композер «зависал» посреди экрана после закрытия клавиатуры —

ЧЕСТНЫЕ ОТВЕТЫ НА ОСТАЛЬНОЕ

«Перепиши фронт на TypeScript / языке Telegram, архив должен весить
30-100 МБ»: у Telegram Web фронт на TypeScript+React, но TS — это язык
для РАЗРАБОТКИ: перед выкладкой он компилируется в тот же JavaScript,
который у тебя уже стоит. Скорость приложения от переписывания на TS
не изменится — TS даёт удобство разработчику, а не мегагерцы браузеру.
Большой вес у Telegram — это эмодзи-спрайты, стикеры, шрифты и звуки,
а не «более быстрый язык». Твой сервер сейчас раздаёт статику без
сборщика — переписывание на TS потребует Node-сборку на сервере и
несколько недель работы с риском сломать всё, что уже работает.
Функциональность от этого не прибавится ни на одну кнопку. Если
всё-таки захочешь — это отдельный большой этап, скажи, спланирую.

«Защита баланса от консоли/подмены кода»: баланс живёт ТОЛЬКО в базе
на сервере. Всё, что человек «поменяет» в консоли браузера — это
картинка у него на экране: любая операция (пополнение, вывод, оплата
с баланса) пересчитывается сервером из базы, клиентская цифра никуда
не отправляется. JWT-токен сессии не в куках «наружу», запросы идут
только на твой домен, есть антифлуд на сообщения и заявки. Полная
защита от DDoS делается не в коде, а перед сервером (Cloudflare уже
стоит у тебя — включи режим «Under Attack» при атаке).

«Голосовое: только блокировка, нет удалить/отправить» — в текущем коде
в залоченном режиме есть все четыре кнопки: корзина слева, пауза,
прослушать, зелёная отправка. Это было сделано в 10.58 — на видео у
тебя старая сборка. После установки проверь ещё раз.

ПРИМЕР СКРИПТА КЛИЕНТА (python, работает с их сервера)
=====================================================================
import requests, time
TOKEN = "токен из LuxFather"
H = {"X-Bot-Token": TOKEN}
BASE = "https://wwweeewww.fit/api/lux/bot"

requests.post(BASE+"/setStart", headers=H, json={
    "start_text": "Привет! Я касса. Жми кнопку:"})
requests.post(BASE+"/setCommands", headers=H, json={"commands":[
    {"command":"help","description":"Помощь","reply":"Пишите оператору"}]})

after = 0
while True:
    r = requests.get(BASE+f"/updates?after_id={after}", headers=H).json()
    for u in r["items"]:
        after = u["id"]
        if u["callback"] == "pay":
            requests.post(BASE+"/sendMessage", headers=H, json={
                "user_id": u["user_id"], "text": "Оплата принята ✅"})
        elif u["text"] == "/start":
            requests.post(BASE+"/sendMessage", headers=H, json={
                "user_id": u["user_id"], "text": "Выберите:",
                "buttons": [[{"t":"Оплатить","d":"pay","c":"g"},
                             {"t":"Отмена","d":"cancel","c":"r"}]]})
    time.sleep(2)
