## 4. SEO-требования (цель — топ-1 по «грузоперевозки Бишкек», «грузовое такси Бишкек», «переезд Бишкек», «грузчики Бишкек», «заказать спринтер Бишкек», «сборка мебели Бишкек»)

- `<html lang="ru">`, `title` ≤ 60 симв. с ключом + гео + УТП, `meta description` 150–160 симв. с призывом, canonical, robots max-image-preview, OG/Twitter, `theme-color`, geo-meta, manifest.
- JSON-LD `@graph`: `MovingCompany` (+`LocalBusiness` данные, `geo`, `openingHoursSpecification`, `areaServed`, `hasOfferCatalog` с услугами/тарифами, `sameAs` пусто не ставить), `WebSite`, `WebPage`, `FAQPage` (вопросы = FAQ на странице), `BreadcrumbList` (одна ступень), `Service` для 6 услуг. **Без AggregateRating и Review** (self-serving отзывы не проходят по гайдлайнам Google).
- Семантика: один `<h1>`, `h2` для секций, `h3` для карточек; `<main>`, `<nav aria-label>`, `<article>`, `<address>`.
- Ключи естественно в H1/H2/тексте: «грузоперевозки в Бишкеке», «грузовое такси», «квартирный переезд», «офисный переезд», «грузчики», «спринтер», «газель», «сборка мебели», «упаковка вещей», районы Бишкека.
- Все SVG-иллюстрации `aria-hidden="true"` или с `<title>`; изображения с `alt`, `width/height`.
- Быстродействие: критический CSS inline допустим, JS `defer`, шрифты `preload` для 2 файлов (Unbounded cyrillic, Manrope cyrillic), никаких внешних запросов (без CDN, без Google Fonts по сети).
- `robots.txt` (Allow all + Sitemap), `sitemap.xml` (`lastmod` = 2026-09-12), 404 не нужен.
- Счётчики (Яндекс.Метрика / GA4) — оставить закомментированные блоки с пометкой, куда вставить ID.
