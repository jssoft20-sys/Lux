# PayGo 1.13.9.67

**Баланс/лимит 1xBet на главном — через `cashbox.getBalance`.**

## Что меняется

Приложение кассы Mobcash показывает «Баланс»/«Лимит» не из ответа входа
и не из отчёта кассира (там их нет — `mobcash-probe` это подтвердил), а из
отдельного JSON-RPC вызова, которого нет в интеграционной PDF:

```
POST https://admin.mob-cash.com/api/
[ { "jsonrpc":"2.0", "id":1, "method":"cashbox.getBalance",
    "params": { "cashboxID": "<id кассы>" } } ]
→ result: { "balance": …, "limit": … }
```

Это ровно тот вызов, который делает домашний экран кассира (найден в коде
веб-приложения app.mob-cash.com). Адаптер теперь делает его после входа
(только чтение, ничего не зачисляет) и раскладывает:

- `balance` → наш **«Вывод»** (сколько уже принято / можно вывести),
- `limit` → наша **«Касса»** (сколько ещё можно зачислять игрокам).

Хост — корень `/api/` того же домена, что и вход
(`admin.mob-cash.com/api/`, проверено: без токена отвечает `401`,
значит путь верный). Если вызов когда-нибудь вернёт не-2xx — откат на
отчёт кассира, затем на «Касса на связи» без числа. **Регрессии нет:**
в худшем случае числа просто не появятся, но ничего не сломается.

Также: `_pick_balance_limit` понимает имена полей кассы `controlBalance`
и `limitAmount`. Команда `mobcash-probe` теперь печатает сырые ответы
входа, `cashbox.getBalance` и отчёта кассира (секреты вырезаны).

## Про «фейк GPS»

Запрошенная подмена геолокации входа **не делалась** — это обход проверки
местоположения кассы, и этого в коде нет. Для баланса она и не нужна:
вход и так проходит (`HTTP 200`), числа отдаёт отдельный endpoint.

## Код

Меняются только `backend/paygo/providers/mobcash.py` и
`backend/paygo/cli.py`. Фронтенд не меняется (главный экран уже умеет
показывать обе суммы с 1.13.9.65 — раньше они просто были пустые).

## Установка

Один блок в терминал (root, `/home`): `installer/paygo-1.13.9.67-paste.txt`
или распакуйте `installer/PayGo-1.13.9.67-Update.zip`.

После установки проверьте: откройте главный экран (Ctrl+F5). Если числа
не появились сразу — `sudo -u paygo /home/PayGo/venv/bin/paygo-admin mobcash-probe`
покажет сырой ответ `cashbox.getBalance`.
