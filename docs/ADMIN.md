# Somex Control Center — руководство

Вход: `admin.somex.kg` (dev: `http://localhost:5174`). Email + пароль → TOTP (первый вход — настройка 2FA обязательна). Все действия попадают в неизменяемый аудит с причиной.

## Роли

| Роль | Права |
|---|---|
| SUPERADMIN | всё, включая настройки, администраторов, систему |
| COMPLIANCE | KYC, AML/депозиты, споры (арбитраж), заморозки/баны, чёрный список, объявления, отмена сделок |
| FINANCE | выводы (одобрить/отклонить/повторить), депозиты, hot wallet (синк, лимиты, заморозка), корректировки баланса, курс |
| RISK | Risk Engine (ревью, веса правил), устройства (блокировка), чёрный список, заморозки, флаги пользователей |
| SUPPORT | тикеты, заморозка, завершение сессий, сброс PIN, объявления, отмена сделок |
| VIEWER | только чтение |

## Разделы

* **Дашборд** — KPI (пользователи, эскроу, обязательства, оборот, комиссии, hot wallet), очереди (KYC, удержанные депозиты, выводы, споры, risk), графики, live-лента подозрительной активности и аудита.
* **Пользователи** — поиск, карточка: балансы, безопасность, KYC, **связанные аккаунты**, способы оплаты, IP, сделки, депозиты/выводы, risk-события, устройства/сессии, леджер. Действия: заморозить/разморозить/ограничить/забанить, флаги (уровень KYC, заморозка выводов/торговли), завершить сессии, сбросить устройства/PIN, корректировка баланса, заметка.
* **KYC** — очередь ручной проверки с ответом провайдера, дублями документов, одобрение (VERIFIED/ADVANCED) или отклонение с причиной.
* **AML / Депозиты** — удержанные поступления с результатом screening, зачислить/отклонить, отправить адрес в чёрный список.
* **Выводы** — очередь одобрения с risk-сигналами, одобрить/отклонить (средства возвращаются)/повторить.
* **Кошельки** — hot wallet (баланс, лимиты, **экстренная заморозка**), обязательства, сверка леджера, все проводки.
* **P2P сделки** — live-таблица; карточка сделки: обе стороны с ФИО и рисками, реквизиты, декларация оплаты с чеком, отпуск, спор, системные события, чат (с флагами увода за пределы платформы), risk-сигналы; отмена администратором.
* **Объявления**, **Эскроу** (что заблокировано и под какие сделки).
* **Споры** — арбитраж: хронология, чат, чек, доказательства; решение RELEASE / REFUND / PARTIAL с обоснованием (обе стороны получают уведомление).
* **Risk Engine** — события с сигналами и ревью (фрод / ложное / отмечено), правила и веса.
* **Устройства** — кластеры общих fingerprint и IP, блокировка устройств.
* **Чёрный список** — телефоны, адреса, документы, IP, устройства, счета, ФИО (хранятся хэши) + проверка значения.
* **Аудит** — журнал с проверкой хэш-цепочки, before/after/meta по клику.
* **Поддержка**, **Банки и курс** (включение банков, «видно ли имя плательщика», справочный курс USDT/KGS).
* **Настройки** — общие, безопасность (OTP, cooldown, 2FA, allowlist), лимиты и комиссии, Risk Engine, WhatsApp (Wappi), KYC (Didit), SMTP, блокчейн (TronGrid, xpub, hot wallet, заморозки, screening), файлы/ClamAV. Секреты шифруются; кнопка «Проверить подключение» для каждого сервиса.
* **Администраторы** — создание, роли, IP allowlist, сброс 2FA, отключение.
* **Система** — состояние интеграций и окружения.
