# PayGo 1.13.9.66

**Терпимый установщик — откат только из-за основных сервисов.**

## Что меняется

Обновление больше **не откатывается целиком**, если после перезапуска
«упал» один из вспомогательных ботов (например `paygo-win-bot`,
`paygo-global-bot`, `paygo-1win-live`). Такой бот был сломан ещё до
обновления (своя настройка Telegram/токен) и не должен мешать выкатить
новую версию.

Теперь решение об откате принимают только **основные сервисы**:

```
paygo-backend  paygo-worker  paygo-bot  paygo-support  paygo-redirect
```

- Любой из основных не поднялся → **автоматический откат** (как раньше).
- Вспомогательный бот не поднялся → **предупреждение**, обновление
  остаётся: `эти вспомогательные сервисы не поднялись (обновление не
  откатывается — чините отдельно): …`

Плюс: ботам дают время на вход в Telegram — после перезапуска установщик
ждёт и до трёх раз перепроверяет сервисы, которые ещё в состоянии
`activating (start)` (не `auto-restart`), прежде чем считать их упавшими.

## Код

Код приложения **идентичен 1.13.9.65** (коммит `d0d6fb4`). Изменён только
`install.sh` установщика — логика перезапуска/проверки сервисов.

## Проверка (симуляции установщика)

| Сценарий | Итог |
|---|---|
| Чистая установка поверх 1.13.9.40 | успех, файлы 66, все сервисы active |
| Обновление поверх 1.13.9.65 | успех, файлы 66 |
| Вспомогательный `paygo-win-bot` крэш-луп | **успех**, предупреждение, без отката |
| Основной `paygo-backend` упал | **откат** (rc=1, файлы возвращены) |

## Установка

Один блок в терминал (root, `/home`): см.
`installer/paygo-1.13.9.66-paste.txt` или распакуйте
`installer/PayGo-1.13.9.66-Update.zip` и запустите
`install.sh --check` затем `install.sh`.

Данные кассы 1xBet/Mobcash уже настроены на сервере (с 1.13.9.63) —
отдельный `mobcash-setup` для этого обновления не нужен. После установки
станет доступна команда `paygo-admin mobcash-probe` — она показывает сырые
поля входа/отчёта Mobcash, если баланс/лимит не отображаются на главном.
