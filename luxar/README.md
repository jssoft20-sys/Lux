# Luxar Autorent

Сайт аренды автомобилей с онлайн-бронированием, оплатой **ELQR (Optima Bank, любой банк по QR)** и **USDT (Binance)**, админкой, напоминаниями в WhatsApp и автоматической проверкой оплат.

## Запуск на сервере (IP:7088)

```bash
# архив загружен в /home
cd /home && unzip luxar.zip -d /home        # появится папка /home/luxar
cd /home/luxar && bash install.sh            # ставит Node.js (если нет), зависимости, службу systemd
```

После установки:

- сайт — `http://IP-сервера:7088`
- админка — `http://IP-сервера:7088/admin`
- логин и пароль администратора — в файле `.env` (`ADMIN_LOGIN`, `ADMIN_PASSWORD`), применяются при первом запуске; далее меняются в админке → Настройки → Безопасность
- сброс пароля: `node scripts/reset-admin.js luxar НовыйПароль` и перезапуск

Ручной запуск без systemd: `npm start` (порт и адрес в `.env`). Логи службы: `journalctl -u luxar -f`.
Зависимости чисто JavaScript, компиляторы не нужны. Node.js 18+ (рекомендуется 22).

## Что где настраивается (админка → Настройки)

| Раздел | Что указать |
|---|---|
| Компания | название, телефон, WhatsApp, адрес, режим работы, Instagram |
| Сайт | публичный адрес (для ссылок в сообщениях), часы работы, сроки аренды, холд без оплаты, доставка, условия |
| Курсы | `1 $ = сом` (для ELQR) и `1 $ = USDT` |
| Optima ELQR | **ID компании** и **API-ключ** из Optima Business → «Проверить и найти точку» — торговая точка и касса подставятся сами. Callback-URL и логин/пароль — только если появится домен с HTTPS |
| USDT | адреса кошельков по сетям (TRC20, BEP20, …), Binance Pay ID, окно оплаты, уникальные копейки |
| Почта | пресеты Gmail / Яндекс / Timeweb / Mail.ru / свой сервер; SMTP для писем, IMAP для чтения уведомлений Binance о пополнении |
| WhatsApp | Profile ID и токен wappi.pro, номер администратора, за сколько часов напоминать, шаблоны сообщений |
| Безопасность | логин и пароль администратора |

## Как работает оплата

**ELQR.** Сервер запрашивает у Optima Business динамический QR (`/api/v2/generate/qr`, тип `DEEP_LINKS_BY_SALE_POINT`, при недоступности типа — автоматический перебор `WEB_PARTNER_BY_SALE_POINT` и др.). Клиент видит QR, кнопки «Открыть в приложении банка» и ссылку. Сервер опрашивает статус (`/api/v1/get-qr-transaction-info`) каждые 4 секунды (требование банка — запрос статуса в течение 12 секунд после оплаты). При `PROCESSED` бронь подтверждается, клиенту и администратору уходят уведомления. Callback (`POST /api/v1/callback`, Basic Auth) тоже поддержан — банк требует для него HTTPS.

**USDT.** Клиент выбирает сеть, видит адрес, QR и точную сумму (с уникальными копейками). Поступление определяется по письму Binance о пополнении: сервер читает почту по IMAP каждые N секунд, находит сумму `… USDT`, сопоставляет с ожидающей оплатой и подтверждает бронь. Кнопка «Я оплатил» переводит платёж в статус «Проверить» и уведомляет администратора — подтвердить можно вручную в админке → Платежи. В Binance включите e-mail уведомления о депозитах.

## Аренда и продление

- на карточке машины видно, свободна она или занята и до какого времени;
- бронь с сайта удерживает машину на время оплаты (по умолчанию 30 минут), затем снимается;
- за N часов до окончания (по умолчанию 3) клиенту в WhatsApp уходит ссылка `http://IP:7088/b/<код>`, где он выбирает дни и оплачивает продление; кнопка «Продлить» есть и на карточке машины (поиск по номеру телефона);
- администратор в разделе «Брони» видит все аренды, время окончания, номер клиента, может продлить, отметить оплату, завершить, отправить напоминание, открыть WhatsApp с готовой ссылкой.

## Данные

Всё хранится в `data/db.json` (резервные копии — `data/backups/`, одна в день, 30 штук). Фото — в `uploads/`. Экспорт CSV: брони, клиенты, платежи (админка → соответствующие разделы).

## Структура

```
server.js            — вход, порт 7088
src/routes/          — публичное API, админ-API, callback банка
src/services/        — optima.js, payments.js, mail.js, whatsapp.js, notify.js, scheduler.js, pricing.js, availability.js
public/              — сайт (index.html, js/, css/), админка (admin/), логотип и иконки (assets/), стартовые фото (seed/)
deploy/              — systemd-служба, пример nginx
```

## Домен и HTTPS (позже)

Поставьте nginx с сертификатом по `deploy/nginx.example.conf`, в `.env` укажите `TRUST_PROXY=1`, в админке → Сайт → публичный адрес `https://домен`. Тогда можно включить callback от Optima Bank.
