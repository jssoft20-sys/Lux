3. ЧТО ПОЯВИЛОСЬ В МЕНЮ АДМИНКИ
----------------------------------------------------------------

Меню → четыре новых раздела в самом верху:

  • ПОЛЬЗОВАТЕЛИ
  • ИДЕНТИФИКАЦИЯ
  • БУКМЕКЕРЫ
  • ЧАТ САЙТА


ПОЛЬЗОВАТЕЛИ
------------
Список всех, кто зарегистрирован на сайте.
  – поиск по имени, @нику, почте, телефону, ID и chat_id (кириллица ищется
    в любом регистре);
  – фильтры: Все / На проверке / Заблокированы / Подтверждены / С балансом /
    Персонал, у каждого счётчик;
  – сводка сверху: всего, онлайн, на проверке, в блоке;
  – в строке: аватар, зелёная точка «в сети», бейдж верификации, бейдж роли,
    когда последний раз был в сети, баланс.

Тап по строке открывает карточку с полным управлением:
  – БАЛАНС: «Пополнить» / «Списать» / «Задать» — сумма, быстрые кнопки
    (+100, +500, +1000, +5000), комментарий для клиента. Клиенту приходит
    уведомление, операция пишется в журнал баланса;
  – КОНТАКТЫ: почта, телефон, ID на сайте, Telegram chat_id, дата регистрации,
    последний вход, «был(а) в сети». Тап по строке копирует значение;
  – ИДЕНТИФИКАЦИЯ: фото, статус, кнопки «Подтвердить» / «Отклонить»;
  – ДОСТУП: переключатель блокировки по сайту. При блокировке спрашивается
    причина, все активные сессии клиента завершаются, вход и заявки
    закрываются сразу;
  – РОЛЬ: Пользователь / Поддержка / Оператор чата / Администратор —
    это и есть «назначить аккаунт»;
  – заметка администратора (видна только операторам);
  – кнопка «Открыть чат с клиентом»;
  – последние заявки, движение баланса, устройства, история действий
    операторов по этому клиенту.


ИДЕНТИФИКАЦИЯ
-------------
Очередь проверки документов: вкладки «На проверке / Подтверждены / Отклонены»
со счётчиками. В карточке — селфи (тап открывает во весь экран), имя, почта,
телефон, ID.
  – «Подтвердить» — клиент получает уведомление, что аккаунт подтверждён;
  – «Отклонить» — обязательно указывается причина. Есть готовые формулировки
    («Фото нечёткое — лицо не видно», «На фото несколько человек»,
    «Документ не совпадает с данными профиля», «Истёк срок действия
    документа») плюс своё поле. Причина уходит клиенту в уведомление,
    он может отправить фото заново. Без причины отклонить нельзя.


БУКМЕКЕРЫ
---------
  – общие выключатели: «Пополнения», «Выводы», «Пауза платформы» —
    действуют сразу и на сайт, и на бота;
  – по каждой БК: включение пополнения и вывода отдельно, лимиты
    (пополнение от/до, вывод от/до);
  – КОШЕЛЁК ДЛЯ ПРИЁМА — за каждой БК можно закрепить свой реквизит.
    Если оставить «Как настроено глобально», работает обычный режим
    (случайный или фиксированный из раздела «Кошельки»).
    Заявка на пополнение теперь берёт кошелёк именно так: сначала
    закреплённый за БК, потом глобальный режим.


ЧАТ САЙТА
---------
  – список назначенных аккаунтов с ролями, тап — открывает карточку и смену
    роли;
  – последние сообщения общего чата: закрепить / открепить, открыть автора,
    удалить сообщение.

4. ЗАЯВКИ: ПРАВКА И ОТМЕНА
----------------------------------------------------------------

Теперь в модальном окне заявки есть всё то же, что и в полном виде.

Модальное окно (быстрый просмотр) — вторая строка кнопок:
  «Изменить» • «Отменить» • «Чек»
Плюс в блоке клиента показываются почта и телефон, и есть переход
«Полный профиль на сайте».

Полный вид заявки — сверху кнопки «Изменить заявку» и «Отменить».

ИЗМЕНИТЬ — можно поменять:
  – ID счёта игрока;
  – сумму;
  – букмекера.
Для пополнения при смене суммы автоматически пересобирается точная сумма
к оплате (с уникальными тыйынами) и заново генерируется QR со ссылками
банков. Клиенту уходит уведомление, что именно изменилось.
Завершённую заявку изменить нельзя — кнопки блокируются.

ОТМЕНИТЬ — заявка получает статус «Отменено», клиенту уходит уведомление
с причиной. Есть готовые причины (Клиент передумал, Ошибка в реквизитах,
Оплата не поступила, Дубликат заявки, Подозрение на мошенничество) и своё
поле. Если пополнение БК шло с внутреннего баланса — деньги возвращаются
на баланс автоматически, повторная отмена деньги второй раз не вернёт.

5. ЧЕК: iPhone И ANDROID — БАГИ УБРАНЫ
----------------------------------------------------------------

Было: сервер смотрел на расширение файла и разрешал только .png/.jpg/.webp.
iPhone из галереи отдаёт IMG_XXXX.HEIC, Android часто отдаёт файл вообще
без расширения — обе загрузки падали с ошибкой.

Стало:
  – в браузере фото сначала пережимается в JPEG через canvas (до 2000 px,
    поворот по EXIF). На iPhone так решается HEIC, на Android — кадры
    на 8–12 МБ;
  – сервер больше не смотрит на имя файла: он определяет формат по
    содержимому и перекодирует в чистый JPEG. Имя без расширения,
    Screenshot.png, фото с камеры — всё принимается;
  – лимит поднят с 12 до 25 МБ;
  – если файл всё-таки нечитаемый, приходит понятное сообщение, а для HEIC —
    подсказка переключить iPhone на «Наиболее совместимый»;
  – чек можно приложить и к пополнению, не только к выводу;
  – выбор «Камера» / «Галерея» есть и в модальном окне, и в полном виде,
    и для вывода, и для пополнения.
