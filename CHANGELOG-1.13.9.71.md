# PayGo 1.13.9.71

**На главном у 1xBet — реальный оборот смены.**

Точный Баланс/Лимит кассы достаётся только через вход в кабинет из
браузера (вход защищён от ботов — автоматом нельзя, а вход с чужого IP
может заблокировать кассу). Поэтому по умолчанию на главном у 1xBet
теперь показываются числа, которые интеграционный токен **может**
прочитать — оборот смены из отчёта кассира:

- **Пополнено** (сколько ушло игрокам за смену) и **Вывод** (сколько
  выплачено). Сейчас это `19 439.98` / `4 239`.
- Реально, живьём, без токена и без входа.

В `balance()`: если токена кабинета нет, берём из отчёта кассира
`depositAmount`/`withdrawalAmount` и возвращаем с пометкой «Оборот за
смену». Главный экран и карточка кассы по этой пометке подписывают числа
«Пополнено»/«Вывод» (а не «Касса»/«Вывод»). Mobcash исключён из порога
«мало в кассе» и авто-отключения — оборот это не остаток.

Если позже вставишь refresh-токен кабинета (команда `mobcash-token`,
1.13.9.70), на главном появится **точный** Баланс/Лимит вместо оборота.
